Introducción

Esta página tiene un patrón SVG de cuadrícula como imagen de fondo, además de un gradiente azul claro. Al imprimir, ambos se mantienen gracias a print-color-adjust: exact.

🔥 Este bloque tiene fondo con gradiente morado. También se imprime.

Puntos clave

  • Fondo con patrón SVG embebido (data URI).
  • Gradiente CSS de fondo.
  • Bloques con colores sólidos.
  • Overlays semitransparentes.
